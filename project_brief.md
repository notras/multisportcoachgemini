# My agent: multisport-coach
One-liner: A conversational trainee assistant that helps endurance athletes track, plan, and optimize workouts across running, trail running, roller skiing, and cycling.

Tool coverage:
- Memory: Remembers athlete profile (fitness level, heart rate/power zones, past workouts, preferred gear, injury history, recovery state)
- Tools: log_activity, get_training_plan, get_gear_recommendation
- Catalog/UI: Activity logs table, weekly training schedule cards, gear collection
- Image gen: Route elevation graphics, motivational achievement badges
- Sandbox: Computes Training Stress Score (TSS), elevation pacing adjustments, power-to-weight ratios

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): code sandbox for TSS/power calculations, Maps API for trail routing
